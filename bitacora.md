# Bitácora de aprendizaje

## Día 3 — 8 de junio 2026

Después de 3 semanas sin tocar el código (vacaciones), regresé y todo seguía intacto.

Hoy entendí que Git no es magia. Es una cámara de fotos para mi código.

Cada commit es una foto en el tiempo. Si algo se rompe, vuelvo a la foto anterior.

Mi primer comando que entiendo de verdad: `git log` — muestra todas mis fotos.
Lección extra del Día 3: Git solo fotografía cuando hay cambios reales. Sin cambios, no hay commit.
